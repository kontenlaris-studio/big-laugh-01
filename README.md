One line, big laugh: a vending machine that refuses a refund but hands
over a second bag of chips instead — a negotiation where both sides
walk away convinced they won.

## Run it

```sh
python3 main.py
```

The entry line (114 characters) is written to `/output/entry.txt`.
Running it twice produces byte-identical output — the program is
fully deterministic and uses only the Python standard library.

## How to run

No dependencies to install: any Python 3 will do. From this folder,
`python3 main.py` is the whole setup; check the result with
`cat /output/entry.txt`.
